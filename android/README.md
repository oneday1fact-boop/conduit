# Android project placeholder

The uploaded AAB/APKs are compiled output, not a substitute for the original Android Studio/Capacitor source project.

Place the **actual existing** native Android project here once it is available, preserving its Gradle wrapper and plugin configuration. Do not reconstruct an arbitrary Android project from the AAB: that would risk introducing changes to game behavior, permissions, package identity and release signing.

Read [../ANDROID_RELEASE.md](../ANDROID_RELEASE.md) for the release checklist. Never commit a keystore or passwords.
