# CONDUIT 1.1.0 candidate (version code 3)

Pro price: **US$2.99, one time**, product `conduit_pro_lifetime`. Localized prices come from Google Play. This grants available past Daily puzzles and a calendar with completion/in-progress states. Daily and the existing three Practice puzzles remain free. Pro does not remove or add ads: rewarded Hint ads remain optional, with one hint per puzzle. Archive wins do not change Daily streaks.

## Implemented

- Three-mode navigation, compact phone layout, Pro upgrade screen and monthly archive calendar.
- Native Google sign-in through Android Credential Manager, matching the existing enabled provider. Optional email/password/reset/verification code remains disabled unless the owner explicitly enables that provider.
- Per-account cloud progress, local guest migration, separate local account saves, restoration across devices and completion-preserving merges. Guest data survives sign-out. Only puzzle progress and Daily completion history sync; sound/theme/haptics stay device preferences.
- Native Play Billing 9.1.0 purchase/restore bridge. Pending/canceled purchases never unlock Pro. A hashed Firebase UID binds the purchase to its CONDUIT account.
- Firebase callable functions verify purchases through the Google Play Developer API, acknowledge them, and write server-only Pro entitlements. Refund notification and periodic rechecks revoke invalid entitlements. Clients cannot write entitlements or purchase tokens.
- In-app account/cloud-progress deletion with recent sign-in required. Purchase deletion support limitations are disclosed before confirmation.
- Existing package ID and signing configuration retained. Production build script retains real AdMob app/rewarded IDs and child/under-age consent flags; debug builds retain test ads.

## Known limits / honest status

The existing Firebase public config is included, with service readiness intentionally **false** until the reviewed rules/backend are deployed. Free play works; account/purchase controls clearly report unavailable. No actual payment, live cloud sync, newly deployed rules/functions, or signed Play release has been verified yet. Google remains the enabled provider; no authentication providers or security rules were changed in the console. Pro currently requires an online entitlement check after app launch; no permanent editable local unlock flag is stored.

Account deletion removes Firebase Auth and cloud progress. It does not refund a Google Play purchase. A temporary random account-ID deletion guard is retained beyond ID-token expiry (cleaned by the six-hour maintenance job) to prevent stale clients recreating deleted data. A minimal non-reversible purchase-token hash is retained to guard against reuse; moving a deleted account's purchase requires support. Review this retention disclosure and support process before launch. Add abuse protection/App Check and monitor billing/Firestore costs before public availability.
