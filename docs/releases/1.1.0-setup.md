# CONDUIT 1.1.0 candidate (version code 3)

Pro is **US$2.99 once**. Daily / Practice / Pro navigation and the archive calendar are implemented. Existing app identity, signing configuration, guest saves, 800 puzzles, three free Practice puzzles and optional rewarded Hint behavior remain intact.

The owner selected free Firebase Spark on 29 October 2026. The former Firebase Functions backend has been removed. Use the current [Spark/free-tier activation checklist](1.1.0-free-backend.md) and [proposed privacy updates](1.1.0-privacy-draft.md).

The existing project is `conduit-22893`; Google is its enabled sign-in provider. Its public account-bridge configuration is included. Email/password remains disabled. Account/cloud services remain off until deployment and review. No live purchase, refund, cross-device restoration or signed Play update has been completed merely by compiling this candidate.

Build/test instructions: `npm ci`, `npm run validate`, `npm ci --prefix billing-worker`, `npm test --prefix billing-worker`, `npm run build --prefix billing-worker`, `npm run build:cloud`, `npx cap sync android`. CI additionally compiles Android and tests Firestore access rules in an isolated emulator.

Proposed release notes (publish only after activation/tests):
- Choose Daily, Practice or Pro from the new navigation.
- Pro unlocks previous Daily puzzles with completion markers, for a US$2.99 one-time purchase (local prices vary).
- Sign in with Google to restore puzzle progress and Pro across devices.
- More room for the phone board and word bank, with settings in the header.

No production availability or sensitive Play declarations are to be changed without the owner's review. Use the original signing key; never create a replacement key to work around missing signing access.
